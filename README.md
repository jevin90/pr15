# Goods Product Management

A React product-management app for creating products and viewing a live catalog.

## Features

- Add products with a name, category, price, quantity, and optional description.
- See new products appear at the top of the catalog immediately.
- Review product counts, inventory value, and stock status.
- Use native form validation for required fields and numeric values.
- Responsive layout for desktop, tablet, and mobile screens.

## Run locally

```sh
npm install
npm run dev
```

Product data is held in React state and resets when the page is reloaded.
